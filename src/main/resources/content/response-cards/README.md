# 공식 대응 카드

피해 대응에서 보여주는 카드예요. 기관명, 연락처, 링크는 AI가 만들지 않고 여기서만 가져와요.

카드 하나는 YAML 파일 하나로 두고, 아래 항목을 반드시 채워요.

| 항목 | 설명 |
|---|---|
| `id`, `version` | 카드 식별자와 버전. DB에는 이 둘만 남겨요 |
| `urgent` | 긴급 카드 여부. 긴급 카드는 검색을 기다리지 않고 먼저 보여줘요 |
| `when` | 적용 조건. 예: `송금: 예` |
| `do_now` | 지금 할 일 |
| `contacts` | 연락할 곳(기관명, 전화, 공식 링크) |
| `prepare` | 준비할 자료 |
| `source`, `checked_at` | 출처와 확인일. 비어 있으면 화면에 내보내지 않아요 |
| `reviewed` | 팀 검토 완료 여부 |

연락처와 링크는 공식 사이트에서 직접 확인한 값만 넣어요.
