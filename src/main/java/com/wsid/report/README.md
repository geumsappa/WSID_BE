# report — 훈련 결과 리포트

RPT-01~05는 로그인한 본인의 훈련 리포트만 제공해요. 다른 회원의 리포트와 존재하지 않는 리포트는 모두 404예요. 경로와 인증 방법은 [API 문서](../../../../../../../docs/api.md)를 참고하세요.

- 기존 훈련이 완료되면 종료 트랜잭션 안에서 제한된 행동 정보만으로 기본 평가를 저장해요. `report_json`에는 대화 원문을 넣지 않아요.
- 저장 요청은 `saved_at` 기록과 해당 훈련의 대화·진행 데이터 정리를 한 트랜잭션에서 처리해요. 같은 요청을 반복해도 처음 저장한 시각을 유지해요.
- 목록은 저장한 리포트만 훈련 완료 시각 내림차순으로 반환해요. 완료 시각이 같으면 리포트 ID 내림차순을 사용해요. 상세 조회도 저장한 리포트만 반환해요.
- PDF는 소유권을 확인한 뒤 평가 결과로 즉석 생성해요. PDFBox와 함께 동봉한 나눔고딕을 사용하고, PDF 파일은 DB에 저장하지 않아요.

TRN-11 종료 요청은 기본 모드에서 규칙 기반 평가를 만들고, HTTP 모드에서는 노션 계약의 AI-05를 호출해 결과를 저장해요. 호출 실패 시 훈련 완료 상태나 리포트를 저장하지 않아서 같은 상태로 다시 종료할 수 있어요.
